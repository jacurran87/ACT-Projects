**ACT Projects** is a DaVinci Resolve custom tools project primarily for animation
compositing.

## Download
Get the latest version **[here](https://github.com/AbiYasidAlMajid/ACT-Projects/releases)**.

## Included Tools
Currently, the project includes the following tools:
- **Simple Anti-Aliasing (Simple AA):** A custom tool designed to smooth out jagged edges (aliasing) on 2D drawings and animations, without blurring the entire image.

*(More tools will be added in future updates)*

## Requirements
- **Software:** DaVinci Resolve 18.0 or later (recommended)
- **Editions:** Free and Studio versions

## Installation
1. Download the tools.
2. Copy the `.fuse` files into your DaVinci Resolve Fusion's "Fuses" directory:
   - **Windows:** `C:\Users\username\AppData\Roaming\Blackmagic Design\DaVinci Resolve\Support\Fusion\Fuses`
   - **macOS:** `Macintosh HD/Users/username/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Fuses`
   - **Linux:** `home/username/.local/share/DaVinci Resolve/Fusion/Fuses`
3. Restart DaVinci Resolve.

## Documentation
For detailed instructions on how to use each tool, including parameter explanations and visual examples, please refer to the `ACTProjects-UserManual.pdf` included in the latest release.
